# Triage workspace

Serverpod 4.0.4 workspace containing `triage_server` and the generated `triage_client`. Uses official UUID authentication, session-owned inbox CRUD, typed user-scoped events, formal one-to-one reminder/recording relations, and a reminder future-call hook.

Includes `triage_flutter`, the custom voice inbox client. See [SERVERPOD_SETUP.md](../docs/SERVERPOD_SETUP.md) for backend setup and [FLUTTER_UI.md](../docs/FLUTTER_UI.md) for the UI, voice pipeline, run instructions, tests, and current privacy limitations.
